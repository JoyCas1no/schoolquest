# SchoolQuest — правила проекта

Браузерная учебная игра для детей 1–11 классов: бой с монстрами, приручение питомцев, предметы, рейтинги. Решения и их обоснование: `docs/handoff.md`. Термины: `GLOSSARY.md`.

## Как работать с владельцем
- Отвечать по-русски, коротко; честно писать, что не проверено (особенно на телефоне).
- Новая крупная идея начинается с раунда вопросов (скилл grilling): нумерованные ❓ с рекомендацией ➡️, потом ждать ответа. Мелкие правки и баги делать без опроса.
- Работать экономно: не плодить сессии и субагентов.
- Коммиты: `git -c user.name=dev -c user.email=cas1no21@outlook.com commit ...`, строки об авторстве не добавлять.
- Картинки рисовать кодом или эмодзи, без внешних сервисов. Контент безопасный для детей, без реальных людей и организаций.
- Создавать аккаунты и вводить пароли за владельца нельзя: он входит сам (GitHub, Supabase), дальше я работаю в его сессии через Chrome.
- Публикация: только репозиторий `schoolquest` на GitHub Pages и отдельный проект Supabase. Данные Pristav не смешивать.

## Устройство кода
- Исходники в `src/`: `head.html` (стили и каркас), `data.js` (вопросы, монстры, классы, реплики), `cloud.js` (вход и облачное сохранение, Supabase), `engine.js` (звук, состояние, экраны, бой), `tail.html`.
- Облако: Supabase-проект `schoolquest`, схема в `supabase/schema.sql`. Вход по логину, служебная почта `<логин>@schoolquest.game`. Пароли не храним и не логируем, ключ `service_role` не копируем. Облачный тест: `node tools/_cloudtest.mjs` (потом удалить `sqtest_*`).
- `node tools/build.mjs` собирает `index.html`. Собранный файл руками не править.
- 3D-прототип: `proto3d.html` + `src/proto3d.js` (сцена), three.js подгружается с CDN через import map. Одиночная сборка без CDN: `node tools/proto.mjs` (нужен `npm install`). node_modules в репозиторий не коммитить.
- `node tools/check.mjs 200` — сборка, синтаксис, проверка вопросов и математики, 200 случайных прохождений. Запускать перед каждым коммитом.
- Игра без внешних библиотек, один HTML, графика эмодзи и CSS, звук WebAudio.

## Правила для детей (не нарушать)
- Имя героя: можно своё (2–16 букв или цифр, `cleanName`) или из готовых списков. Сейчас оно хранится только на устройстве. **Перед онлайн-рейтингом решить, как показывать чужие имена другим детям** (модерация или только имена из списков), пока этого решения нет. Личных данных ребёнка не собираем, в подсказке просим писать прозвище, а не настоящее имя.
- Общения нет: только готовые реакции и фразы из списка.
- Без покупок за деньги и без рекламы. Скины и питомцы только за игру.
- Ошибка не наказывается жёстко: теряется сердце, всегда есть объяснение. Без кормлений по таймерам и «умирающих» питомцев.
- Мягкое напоминание об отдыхе (30 мин), можно выключить.
